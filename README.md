# PrimeShow - Premium Cinema & Movie Booking Platform

PrimeShow is an OTT and luxury cinema booking application built with React 19, Tailwind CSS, Express, and Node.js.

## 🚀 Project Structure

```
PrimeShow/
├── client/          # Vite + React 19 Frontend UI
├── server/          # Express REST API Backend Server
├── package.json     # Project root script launcher & dependencies
└── README.md        # Project documentation
```

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start both backend server (port 5000) and frontend client (port 5173) concurrently
npm run dev

# Build production bundle
npm run build
```
